Actividad de lectura #1

Luego responda a las siguientes preguntas:
1. ¿Qué significa el acceso directo a las variables? De un ejemplo.
2. ¿Qué significa el acceso indirecto a las variables? De un ejemplo.
3. Qué ventajas y desventajas presenta cada estrategia referida a los getters y setters.


1. El acceso directo a las variables hace referencia a la forma en que se acceden a las variables de instancia de un objeto. Como lo dice y describe, en este caso es de manera directa.
Aquí las variables son referidas directamente por el objeto como: objeto.variable.

2. El acceso indirecto refiere a una estrategia de programación que requiere que para acceder a las variables de instancia se debe hacer solo através de un método. 
Para este necesitamos un método de acceso al valor de la variable, llamado Getter y un método para modificar el valor de una variable de instancia, llamado Setter.
Ejemplo: 
object.getName() (ejemplo getter)
object.setName("new_name") (ejemplo setter)

3. Las ventajas que tiene esta estrategia son varias, la principal es la posibilidad de poner como privados los métodos de acceso o, en caso de necesitarlo, como públicos.
Nos da control de validación sobre los valores que se vayan a settear, para evitar valores inválidos que podrían rompar el invariante.

Una desventaja podría ser la pérdida de legibilidad sobre el código.

Cómo vimos en el ejemplo de calcular sueldos totales, teniendo o no el control de como agregan o quitan empleados otros objetos.
Es importante brindar los métodos y mensajes disponibles para trabajar con las colecciones de datos, agregando una interfaz sobre la colección, para limitar como se trabajará sobre ella y agregando una capa de abstracción.
